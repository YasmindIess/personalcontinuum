# ADR-0002 — Situated position is computed evidence, not decoration

**Status:** Accepted

V2/V2.1 displayed deterministic position values as interface placeholders. The modular foundation removes them from canonical truth and marks every position `uncomputed` until a relation dataset and explicit metric implementation exist.

No follower count, engagement count, or founder rank is permitted to enter the topological contribution function unless explicitly modeled, justified, and labeled as a separate input.
