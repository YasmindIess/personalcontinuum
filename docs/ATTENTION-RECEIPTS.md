# Attention Receipts

Attention is treated as observable continuation, not a manipulation target.

The system may record privacy-respecting, consent-compatible events such as world opened, source inspected, relation expanded, correction submitted, response linked, or claim deliberately initiated. These events can inform which explanatory surfaces deserve refinement.

The system must not convert attention metrics into hidden identity judgments, automated unsolicited mention storms, or unverifiable claims of cultural importance.
