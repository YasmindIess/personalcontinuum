# Operator Identity Grammar v0.1

The ten V2.1 operators are retained as a **basis**, not as the final count of artworks.

Every public signal receives one stable operator identity:

`OI_i = (primary, secondary, deformation, topology, corridor, seed, rendererVersion)`

## Coordinates

- **primary operator** — dominant local equation family.
- **secondary operator** — cross-pressure that prevents a ten-card repetition cycle.
- **deformation law** — how the primary family is bent, sheared, pulsed, folded or contracted.
- **topology motif** — the local membrane/combinatorial support.
- **corridor behavior** — how the provenance-bearing filament traverses the world.
- **seed** — deterministic local variation; never used as evidence.
- **renderer version** — makes visual identity reconstructible across software changes.

## Identity rule

Two slots may share a primary operator while remaining different mathematical identities. An operator identity is stable under viewport changes; responsive rendering changes projection, not identity.

## Public claim rule

The operator identity is an identity of the **rendered situated world**, not an identity claim about the person.

## V3 acceptance test

The 50 operator signatures must be unique. Contact sheets must show strong compositional individuation while a viewer can still recover the shared manifold, corridor grammar and Blochfield visual substrate.
