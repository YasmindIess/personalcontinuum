# Semantic Heptad Protocol v0.1

## Thesis

The seven-word projection is the source code of the situated world.

For a signal with ordered words `w1 … w7`, Personal Continuum compiles:

`H7 = Φ(w7) ∘ Φ(w6) ∘ … ∘ Φ(w1)(S0)`

Composition is intentionally non-commutative. Word order is part of the public-signal projection and therefore part of the reconstruction.

## Atom contract

Every word compiles to one `SemanticAtom` carrying:

- exact source token;
- normalized token;
- ordinal 1–7;
- semantic action;
- curvature;
- symmetry;
- density;
- scale;
- connectivity;
- rhythm;
- radiality;
- polarity;
- deterministic token/context hashes;
- provenance fixed to `projection7`.

## Actions

The initial compiler vocabulary is:

`bind · branch · channel · diffuse · drift · expand · flow · fold · grow · lattice · morph · orbit · perturb · pulse · recurse · reflect · shield · superpose · weave · accumulate`

Explicit lexical rules map strongly interpretable terms to actions. Unmatched words fall back to a deterministic token/context hash mapping. Fallback is reconstructive rendering behavior, not semantic evidence.

## State transport

The compiler begins with a deterministic bounded state and transports it through seven mutations. Every step stores `before` and `after` states, making derivation replayable and inspectable.

## Context

`style`, `themes`, and `persona` influence bounded numeric perturbations, but the seven ordered source tokens remain the visible causal spine.

## Renderer contract

The semantic heptad owns dominant geometry. The V2/V3-draft operator tuple is rendered only as a faint compatibility witness while migration remains incomplete.

## Epistemic boundary

A Semantic Heptad is a deterministic artistic interpretation of a curated public-signal phrase. It is not a measurement of cognition, personality, value, identity, or hidden traits.

## Future work
