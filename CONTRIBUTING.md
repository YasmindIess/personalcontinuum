# Contributing / Change Discipline

Every change should identify the stratum it modifies: substrate, evidence lattice, render membrane, relation multiplex, publication/ingress, or infrastructure.

Changes to epistemic meaning require an ADR or protocol update. Changes to computed position metrics require a versioned formula and reproducible fixture. Changes to publication behavior must preserve manual review for unsolicited tagged content. Changes to source interpretation must never overwrite the previous receipt chain.

Before merge:

1. `npm run check:data`
2. `npm run typecheck`
3. `npm run build`
4. capture desktop/mobile contact sheets when rendering changes
5. record Lighthouse deltas when DOM/runtime behavior changes
6. update the relevant ADR/protocol/roadmap state
